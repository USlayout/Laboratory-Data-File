iperf3 values used for summary calculation

Value source and conversion:
- TCP throughput: end.sum_sent.bits_per_second / 1,000,000 -> Mbps
- UDP throughput: end.sum.bits_per_second / 1,000,000 -> Mbps
- TCP latency: end.streams[0].sender.mean_rtt / 1,000 -> ms
- UDP latency: end.sum.jitter_ms -> ms

For each protocol, the 10 measurements are used to calculate:
- average = sum(values) / 10
- median = average of the 5th and 6th values after sorting
- population standard deviation = sqrt(sum((x - average)^2) / 10)
